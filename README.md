# FoundIt! - Lost & Found Social App

## Project Overview
- **Goal:** Build a mobile application to help people report, find, and recover lost everyday items within communities or campuses.
- **Social Problem:** Losing personal items causes stress and waste. Traditional Lost & Found desks or unorganized social media groups are inefficient and hard to search.
- **Why Mobile?** Smartphones allow instant reporting using cameras for photos and GPS for precise location tagging.

---

## Target User Group
- University students, campus staff, and urban citizens prone to losing items in public spaces or transportation.

---

## Core User Stories (MVP Scope)
1. **As a finder**, I want to upload a photo, description, and location of a found item so the owner can claim it.
2. **As a loser**, I want to search and filter recent items by category or location to check if someone found my belongings.
3. **As a user**, I want clear instructions on where and how to safely retrieve the item.

---

## Tech Stack & Environment
- **Platform:** Android (Mobile)
- **IDE:** Android Studio

---

## Minimum Viable Product (MVP) Features
- [x] Starter app setup & GitHub repository configuration.
- [ ] Main feed displaying recently found items.
- [ ] Real-time search/filtering by title or location.
- [ ] Item detail screen with location and category info.

---

## Out of Scope (For this prototype)
- Real-time chat systems.
- User authentication/login with custom backend servers.
- Payment gateways or rewards.
- App store deployment (classroom prototype only).

---

## Accessibility Goals
- Scalable and readable typography matching system settings.
- Proper content descriptions for icons and interactive components (TalkBack support).
