# AI use disclosure

AI assistance was used to review the project structure, propose repository/ViewModel boundaries, draft the reusable location permission control, form-validation helper, tests and M2 documentation.

All generated code must be reviewed and tested by the student. In particular, the new ViewModels and location control are foundations and are not yet fully connected to every existing Compose screen. The remote API is JSONPlaceholder and is a demonstration service, not a production FoundIt backend. Build, unit-test and physical-device results must be added only after running them locally. The student remains responsible for understanding, adapting and being able to explain every submitted change, in line with course policy.
